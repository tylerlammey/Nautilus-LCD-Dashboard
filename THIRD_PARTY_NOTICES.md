# Third-party components

The MIT license in this repository covers this project's own code and assets.
It does not replace the licenses of its dependencies.

| Component | Purpose | License / source |
| --- | --- | --- |
| Pillow | Render LCD frames | [HPND and bundled notices](https://github.com/python-pillow/Pillow/blob/main/LICENSE) |
| psutil | Process information | [BSD-3-Clause](https://github.com/giampaolo/psutil/blob/master/LICENSE) |
| hidapi Python package | Access the USB HID LCD | [Package and license metadata](https://pypi.org/project/hidapi/); upstream HIDAPI has separate license choices |
| LibreHardwareMonitor 0.9.6 | CPU/GPU sensors | [MPL-2.0 and dependency notices](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/blob/master/LICENSE) |
| PawnIO | Optional signed CPU sensor driver | [Official distribution](https://pawnio.eu/) and [source](https://github.com/namazso/PawnIO) |
| Codex | Read the user's ChatGPT-backed quotas | Installed separately; [OpenAI Codex source and license](https://github.com/openai/codex) |

Python dependencies are installed into the user's private `.venv` by pip.
LibreHardwareMonitor is downloaded from its pinned official release at setup,
with its SHA-256 checked before extraction. Its upstream binary distribution
includes libraries with their own licenses. Source download packages produced
by this project do not redistribute those third-party binaries or the driver.

The Nautilus image-report format was checked against
[OpenLinkHub's Nautilus implementation](https://github.com/jurkovic-nikola/OpenLinkHub/blob/main/src/devices/nautilusLcd/nautilusLcd.go),
which is GPL-3.0-or-later. This project's packet encoder was independently
written; OpenLinkHub source is neither required nor shipped.

Example display images and shortcut icons are generated by this project's
renderer. No Microsoft font files are redistributed.

CORSAIR and OpenAI product names identify compatible hardware and software.
This project is independent and is not affiliated with or endorsed by either
company.
